# 🧠 Симулятор алгоритмов планирования задач

## 1. Общая информация о проекте

Данный проект представляет собой "учебный программный комплекс для моделирования и анализа алгоритмов планирования задач в операционных системах".  
Приложение реализует симуляцию работы процессора с различными алгоритмами планирования и позволяет наглядно сравнивать их характеристики при различных сценариях нагрузки.

Проект разработан в учебных целях и ориентирован на использование в рамках лабораторных, практических и курсовых работ по дисциплинам, связанным с операционными системами и системным программированием.

---

## 2. Цель и назначение проекта

Цель проекта - изучение принципов планирования задач процессором и сравнительный анализ классических алгоритмов планирования.

В рамках проекта решаются следующие задачи:
- моделирование процесса выполнения задач процессором;
- реализация и сравнение алгоритмов FIFO, LIFO и SJF;
- анализ метрик производительности планировщиков;
- демонстрация влияния CPU-bound и IO-bound задач;
- формирование наглядных результатов в графическом интерфейсе.

---

## 3. Реализованные алгоритмы планирования

В проекте реализованы следующие алгоритмы:

- FIFO (First-In First-Out) - задачи выполняются в порядке поступления;
- LIFO (Last-In First-Out) - последняя поступившая задача выполняется первой;
- SJF (Shortest Job First) - выбирается задача с минимальным временем выполнения.

Все алгоритмы реализованы для:
- одного процессора;
- невытесняющего планирования.

---

## 4. Модель симуляции

- Время моделируется в условных тактах симуляции.
- Один такт соответствует одному кванту процессорного времени.
- Процессор в каждый такт либо:
  - выполняет задачу,
  - либо находится в состоянии простоя (idle).
- Поддерживаются два типа задач:
  - CPU-bound - вычислительные задачи;
  - IO-bound - задачи с периодическими IO-блокировками.
- Для IO-bound задач реализована имитация блокировок ввода-вывода.

---

## 5. Метрики производительности

Для каждого алгоритма рассчитываются следующие показатели:

- *Average Waiting Time* - среднее время ожидания задачи;
- *Average Turnaround Time* - среднее время выполнения (оборот);
- *Response Time* - время первого получения процессора;
- *CPU Time* - фактически затраченное процессорное время;
- *Idle Time* - время простоя процессора;
- *Deadline Miss Rate* - количество и процент пропущенных дедлайнов.

Используемые формулы:
- `Turnaround Time = Finish Time − Arrival Time`
- `Waiting Time = Turnaround Time − CPU Time`

Все значения выражаются в тактах симуляции.

---

## 6. Готовые сценарии

В приложении реализованы преднастроенные сценарии, позволяющие демонстрировать особенности алгоритмов:

- *SJF vs FIFO* - CPU-нагруженный сценарий с большим разбросом длительностей задач;
- *Справедливый FIFO* - задачи схожей длительности, результаты алгоритмов близки;
- *Провал LIFO* - плотное поступление задач, демонстрирующее недостатки LIFO;
- *Рабочий день* - смешанная CPU/IO нагрузка, приближённая к реальным условиям.

Сценарии управляют:
- количеством задач;
- плотностью их поступления;
- временем выполнения;
- долей IO-bound задач.
